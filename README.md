# DropNEdit

Auto-edits your videos: gaming and commentary (dead air cut, zooms, sound effects, clips),
professional brand videos (captions, titles, B-roll, logo) and music videos cut to the beat.

## Download

| System | File |
|---|---|
| Windows 10 / 11 | [DropNEdit.exe](https://github.com/hazzyclipz/DropNEdit-releases/raw/main/DropNEdit.exe) |
| Mac (Apple Silicon and Intel, macOS 10.15+) | [DropNEdit-mac.zip](https://github.com/hazzyclipz/DropNEdit-releases/raw/main/DropNEdit-mac.zip) |
| Linux | [DropNEdit-linux.tar.gz](https://github.com/hazzyclipz/DropNEdit-releases/raw/main/DropNEdit-linux.tar.gz) |

DropNEdit needs **FFmpeg** (free). The app installs it for you: press **Install FFmpeg** on the
Projects page (Mac and Linux get a clean copy in DropNEdit's own folder; Windows uses its own installer).

**Mac, first time only:** unzip, drag DropNEdit.app to Applications, then right-click it and choose **Open**
(it is not from the App Store, so macOS asks once).

After that the app updates itself: when a new version is out it shows **Update now**.
